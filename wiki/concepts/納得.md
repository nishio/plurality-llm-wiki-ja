# 納得

「人が内的に理解して受け入れる」という状態を一語で表す JA-native concept。デジタル民主主義 / 熟議 / 合意形成の議論で中心的なキー概念だが、Plurality 本英語版が EN 由来で書かれているため翻訳 JA 版には希にしか現れない。

## 本書 (翻訳 JA 版) での扱い

[[plurality-book]] (JA 翻訳版) 全体で「納得」は 2 箇所のみ:

- [[5-6 多元投票]]「⿻ 投票の限界」: 「**納得**いく妥協に達するための、こうした非常に柔軟で適応性のあるアプローチ」(EN: "a sense of compromise")
- 6-0「⿻ から現実へ」: 「この指摘は直感的に**納得**できるものだが」(EN: "While intuitive")

EN の "sense of" / "intuitive" などを translator (山形浩生) が「納得」で受けた事例。

## native JA デジタル民主主義言説での高頻度使用

### team-mirai 衆院選 2026 マニフェスト

[[team-mirai-manifesto]] 9 章 (くらしと行政) と 10 章 (デジタル民主主義) で「納得」は政策の目的として直接 articulate される:

> 国民が自ら「**使って納得できる**」投票体験を得られるよう設計します (9 章 投票制度の信頼再構築)

> 対立する利害の間から「**誰もが納得できる第三案**」を熟議によって導き出し、建設的な合意形成を実現します (10 章)

> より透明で**納得感**ある意思決定を支えます (10 章)

つまり **「納得」がデジタル民主主義の目的そのもの** として政党マニフェストレベルで articulate されている。EN なら "consensus" / "buy-in" / "legitimacy" / "satisfaction" など複数語に分散される concept が、JA では「納得」一語に統合されている。

## なぜ JA に存在し EN に void か (仮説)

- 日本の伝統的合意形成文化 (根回し / 稟議 / 空気) が「相手が腹落ちして受け入れる」状態を一語で articulate する pressure を歴史的に作ってきた
- 「同意」(formal agreement) / 「理解」(understanding) と異なる **subjective acceptance の状態** を独立した概念として扱う
- デジタル民主主義言説で「納得」がキー概念化するのは、台湾型 vTaiwan / Polis 等の「合意点抽出」志向が日本に到達したとき、既存日本語の「納得」と naturally 接続したため

## Updates

### 2026-06-02: 字義 + 古語「のうとく」の構造的継続性

parent wiki の研究ノート ([nattoku-research-notes](https://github.com/nishio/plurality-llm-wiki/blob/main/wiki/sources/nattoku-research-notes.md)) から「納得」の internal structure を字義レベルで refined:

**字義 decomposition**:
- **納** = いれる / 受け入れる (take in / accept)
- **得** = える / さとる / わかる (grasp / realize)
- 合成 = **外から来た説明や事情を自分の中に取り込んで分かる** という構図

**古語「のうとく」(仏教語)** — 『精選版 日国大』:
- 初出: 1184 年『吾妻鏡』
- 仏教語的意味: 「**他物を受け入れて自己のものにすること**」

現代「なっとく」と古「のうとく」の意味連続性: 「外にあるものを内側に取り込む」が中心構図として継承。これが「納得 = retrace + acceptance」を 一語で carve できる JA-native の構造的根拠。

### 2026-06-02: 4 言語比較 (refined topography)

[[plurality-llm-wiki/wiki/sources/nattoku-research-notes]] と parent analysis の refined finding:

| 言語 | 「納得」coverage | mechanism |
|---|---|---|
| EN | 真の void | 文脈別 paraphrase: be convinced / accept / make sense / buy-in / be satisfied |
| ZH | 真の void | 文脈別 paraphrase: 觉得有道理 / 想通了 / 接受 / 认可 / 信服 / 服气 |
| DE | **構造的 partial overlap** | nachvollziehbar = **retrace 部分のみ**、acceptance 部分は別語 (überzeugend / einleuchtend / einverstanden) |
| JA | **単一語で完全 carve** | retrace + acceptance を統合 (字義 + 仏教語起源で支えられた構造) |

DE は以前「Nachvollziehbarkeit が 納得 core に最も近い」と記述したが、より精密には「**納得 の retrace 構造を carve するが、acceptance 構造は別語に分散している**」。Nachvollziehbarkeit ≠ 納得 in semantic distance。DE で「納得した」により近いのは「überzeugt sein」「einverstanden sein」など。

### 2026-06-02: 「理解 / 同意 / 説得 / 満足」との distinction (英語話者向け説明)

英語話者向けの推奨説明文 ([nattoku-en-explanation](https://github.com/nishio/plurality-llm-wiki/blob/main/raw/nattoku-en-explanation.md) より):

> **Nattoku is a state of internal acceptance.** It means you understand the reason, and the reason feels sufficiently reasonable for you to accept it. So it is stronger than "I understand," but not always the same as "I agree."

英訳の使い分け:

| 日本語 | 近い英語 | 文脈 |
|---|---|---|
| 納得する (確信) | be convinced | 証拠・説明で確信に近づく |
| 納得する (受容) | accept / come to accept | 結果・事情を受け入れる |
| 納得がいく | make sense | 理由が通って見える |
| 納得のいく説明 | a convincing / satisfactory explanation | 疑問解消 |
| 納得してもらう | get buy-in / help them accept it | 組織・合意形成 |
